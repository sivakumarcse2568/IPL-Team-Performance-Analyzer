IPL 2026 Team Performance Analyzer
About the Project

IPL 2026 Team Performance Analyzer is a beginner-friendly Python project developed to analyze and compare IPL 2026 team performance using statistical and graphical analysis.

The project uses a CSV dataset containing team-level performance statistics and provides a menu-driven interface for analyzing the data.

Objectives
Analyze IPL 2026 team performance
Find teams with the highest and lowest performance values
Calculate basic statistical values
Perform data analysis using Pandas and NumPy
Visualize team performance using Matplotlib
Provide an interactive menu-driven analysis

How to Run

Install Python and the required libraries:

pandas
numpy
matplotlib

Then open the project folder in Command Prompt and run:

python main.py
